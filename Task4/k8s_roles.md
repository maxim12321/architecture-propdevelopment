# Защита доступа к кластеру

## Таблица ролей
| Роль            | Права роли                             | Группы пользователей                                       |
| --------------- | -------------------------------------- | ---------------------------------------------------------- |
| `secret-reader` | `get` и `list` в ресурсе `secrets`     | `secure-operator`, это может быть, например, специалист ИБ |
| `pod-writer`    | все "глаголы" для `pods`               | `devops`                                                   |
| `pod-reader`    | `get`, `list` и `watch` для `pods`     | `developer`                                                |
| `logs-reader`   | `get`, `list` и `watch` для `pods/log` | `developer` и `devops`                                     |

## Создание пользователей

В качестве пользователей будем использовать ServiceAccount, т.к. их проще создать, не нужна генерация сертификатов и прочее.
В реальной системе тут было бы создание полноценных пользователей и групп.

```
kubectl apply -f Task4/accounts.yaml
```

## Создание ролей

```
kubectl apply -f Task4/roles.yaml
```

## Связи пользователей с ролями

```
kubectl apply -f Task4/role-bindings.yaml
```
